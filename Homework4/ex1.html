1Knuth’s recurrence for the mean

Given the observations x1, x2, … arriving one at a time, let

Mk = (1/k) ∑i=1..k xi   (mean of the first k values),   SSk = ∑i=1..k (xi − Mk)²   (sum of squares),   M0 = SS0 = 0.

Idea. Express the quantity at step k through the quantity at step k−1 and the new value xk, so that the old data never have to be read again.

k Mk = ∑i=1..k xi = ∑i=1..k−1 xi + xk = (k−1) Mk−1 + xk split off the last term, and recognise (k−1) Mk−1 as the previous sum Mk = [(k−1) Mk−1 + xk] / k = Mk−1 − Mk−1/k + xk/k divide by k and write (k−1)/k = 1 − 1/k
Mk = Mk−1 + (xk − Mk−1) / k The new mean is the old mean corrected by a fraction 1/k of the difference δk = xk − Mk−1.

Two relations that follow immediately and are used below, with δk = xk − Mk−1:

Mk − Mk−1 = δk/kxk − Mk = δk − δk/k = δk (k−1)/k

2Welford’s recurrence for the sum of squares

The same approach: write SSk in terms of SSk−1. The difficulty is that every term (xi − Mk) now contains the new mean Mk, while SSk−1 uses the old one. The trick is to rewrite Mk = Mk−1 + δk/k.

SSk = ∑i=1..k−1 (xi − Mk)² + (xk − Mk)² step 1: separate the new observation from the previous ones ∑i<k (xi − Mk)² = ∑i<k [(xi − Mk−1) − δk/k]² step 2: Mk = Mk−1 + δk/k = ∑i<k (xi − Mk−1)² − 2(δk/k) ∑i<k (xi − Mk−1) + (k−1) δk²/k² step 3: expand the square; the factor δk/k does not depend on i = SSk−1 − 0 + (k−1) δk²/k² step 4: deviations from the mean add up to zero, ∑i<k (xi − Mk−1) = 0 (xk − Mk)² = δk² (k−1)²/k² step 5: last term, using xk − Mk = δk(k−1)/k from Section 1 SSk = SSk−1 + (k−1) δk²/k² + (k−1)² δk²/k² = SSk−1 + (k−1) δk² [1 + (k−1)]/k² step 6: add the two contributions and factor (k−1) δk²/k²
SSk = SSk−1 + (k−1)/k · δk² = SSk−1 + (xk − Mk−1)(xk − Mk) The last form comes from δk²(k−1)/k = δk · (xk − Mk). It is the one used in the code: the product of the deviation from the old mean and the deviation from the new mean. Since (k−1)/k > 0, the increment is never negative, so SSk can only grow.

Independent check with the computational identity SSk = ∑xi² − k Mk². Writing M = Mk−1, xk = M + δ, Mk = M + δ/k:

SSk − SSk−1 = xk² − k Mk² + (k−1) Mk−1² = (M+δ)² − k (M+δ/k)² + (k−1) M² = M² + 2Mδ + δ² − kM² − 2Mδ − δ²/k + (k−1) M² = δ² (1 − 1/k) = (k−1) δ²/k  ✓

3Recurrences for the variance

The sample variance (unbiased, Bessel’s correction) and the population (maximum-likelihood) variance of the first k values are sk² = SSk/(k−1) for k ≥ 2 and vk = SSk/k. Substituting SSk−1 = (k−2) sk−1² and SSk−1 = (k−1) vk−1 in the result of Section 2:

(k−1) sk² = (k−2) sk−1² + (k−1) δk²/k SSk = SSk−1 + (k−1) δk²/k, with SSk = (k−1) sk² and SSk−1 = (k−2) sk−1² k vk = (k−1) vk−1 + (k−1) δk²/k same, with SSk = k vk and SSk−1 = (k−1) vk−1
sk² = [(k−2)/(k−1)] sk−1² + δk²/k   (k ≥ 2, sample variance) vk = [(k−1)/k] vk−1 + (k−1) δk²/k²   (population variance) In practice it is simpler and numerically safer to update SSk and divide at the end: sk² = SSk/(k−1).

4The code

The whole recurrence is the three lines inside the loop (the first one only stores the difference from the old mean, used twice). Nothing else is stored: the memory is three numbers whatever the length of the stream.

Python

# k = number of values seen, mean = M_k, ss = SS_k
k = mean = ss = 0
for x in data:
    k += 1
    d = x - mean            # difference from the OLD mean
    mean += d / k           # Knuth:   M_k  = M_{k-1} + (x_k - M_{k-1}) / k
    ss += d * (x - mean)    # Welford: SS_k = SS_{k-1} + (x_k - M_{k-1}) (x_k - M_k)
variance = ss / (k - 1)     # sample variance (k >= 2); use ss / k for the population variance

JavaScript

let k = 0, mean = 0, ss = 0;
for (const x of data) {
  k++;
  const d = x - mean;       // difference from the OLD mean
  mean += d / k;            // Knuth
  ss += d * (x - mean);     // Welford
}
const variance = ss / (k - 1);

Complete runnable versions are in welford.py (with a self-test) and in js/welford.js, where the same three lines are used by the live demo below and by Exercise 2. Why the product uses both means: with the old mean twice, or the new mean twice, the result would be wrong; the product (xk − Mk−1)(xk − Mk) equals (k−1)/k · δk² exactly.

6Numerical stability

The formula many people learn, s² = (∑x² − (∑x)²/n)/(n−1), subtracts two huge, almost equal numbers when the mean is large compared with the spread, and in double precision loses all its digits (“catastrophic cancellation”). Welford only adds small corrections to the running values. Here the values below are shifted by a constant c; the variance does not change when a constant is added, so the exact answer is known.

The exact variance is computed on the unshifted values. For c = 109 the naive formula is already wrong in the first significant digit (and can even give a negative variance), while Welford and the two-pass method stay exact; for c = 1014 the shifted values are so large that their own representation limits every method.
