1The bivariate dataset (X, F)

Each record is a pair (x, f) of two categorical variables. Choose a dataset: the page works on the individual records (the counts of the published tables are expanded into one record per person) and builds the contingency table from them, exactly as one would do with any raw file.

Numeric variables with more than 12 distinct values are grouped automatically into 5 equal-frequency classes. A first line that looks like a header (non-numeric second field in raw mode and the second line is a pair) can be kept: it is treated as data unless you delete it.

2Contingency table, marginal and conditional frequencies

The contingency table counts the records with X = xi and F = fj: nij. Its row and column totals ni•, n•j are the marginal counts and n = ∑ nij.

3Expected frequencies under independence

If X and F were independent, P(X = xi, F = fj) = P(X = xi)·P(F = fj), estimated with the marginal relative frequencies. The expected count of cell (i, j) is therefore

Eij = n · (ni•/n) · (n•j/n) = ni• n•j / n

4Pearson’s chi-square test of independence

χ² = ∑i,j (Oij − Eij)² / Eij,    df = (r − 1)(c − 1),    p = P(χ²df ≥ χ²obs) H0: X and F are independent    H1: X and F are dependent (associated). Reject H0 when p < α, i.e. when χ² exceeds the critical value.

5Theory in brief

Independence in probability

  • Events. A and B are independent if P(A ∩ B) = P(A) P(B); when P(B) > 0 this means P(A | B) = P(A): knowing B does not change the probability of A.
  • Discrete random variables. X and F are independent if P(X = x, F = f) = P(X = x) P(F = f) for all pairs (x, f); equivalently P(F = f | X = x) = P(F = f) for every x (all conditional distributions coincide with the marginal one), equivalently the joint cdf factorises. For a table this means that all the row profiles are equal.
  • Independence implies zero covariance, not the converse: if X is uniform on {−1, 0, 1} and F = X², then Cov(X, F) = 0 but F is a function of X.

From probabilities to the sample

  • The sample versions are the relative frequencies fij = nij/n, fi• = ni•/n, f•j = n•j/n, and the conditional frequencies fj|i = nij/ni•. Empirical independence would be fij = fi• f•j, i.e. nij = Eij. Because of sampling variability, even independent variables never give exactly nij = Eij: we need a test to decide whether the differences are too large to be chance.
  • Why (O − E)²/E. Under H0 each count Oij has mean Eij and variance about Eij, so (O − E)/√E is approximately N(0, 1) and its square is approximately χ²(1).
  • Why df = (r − 1)(c − 1). There are rc cells; one linear constraint (the total n) and the r − 1 and c − 1 independent parameters estimated from the margins remove rc − 1 − (r − 1) − (c − 1) = (r − 1)(c − 1) degrees of freedom. By Pearson’s theorem (1900) χ² is asymptotically χ²(df) under H0.
  • The p-value is the probability, if H0 were true, of a statistic at least as large as the observed one: p = Q(df/2, χ²/2), the regularised upper incomplete gamma function, implemented here from scratch (series + continued fraction) and checked against SciPy.
  • Conditions. Independent observations; n large enough for the approximation (rule of thumb: all Eij ≥ 5, or at least 80% of them ≥ 5 and none below 1). Otherwise use Fisher’s exact test (2×2), merge categories, or a permutation test, as done below.

6Interpretation and conclusions

Statistical association is not causation

  • What the test says. A small p-value says that the data are hard to reconcile with independence: X and F are statistically associated. It says nothing about why, nor about the direction: the chi-square statistic is symmetric in X and F.
  • Possible explanations of an association: X influences F; F influences X (reverse causation); a third variable Z influences both (confounding); the sample was selected in a way that links them (selection bias); or chance (a 5% false-positive rate is built into every test at α = 0.05).
  • Confounding and Simpson’s paradox. An association in the pooled table can vanish or reverse inside the strata of a third variable (see the Berkeley data: the pooled table shows a gap against women, the department-level tables do not). Conditioning on the right variables matters, and which variables are right depends on the causal story, not on the data alone.
  • Significance is not importance. With a large n, tiny departures from independence are “significant”; always report an effect size (Cramér’s V, odds ratio) and look at which cells drive the statistic. Try the simulated dataset with a small s and increasing n.
  • Not rejecting H0 is not proof of independence: with a small n the test has little power. Independence (zero association) is also different from zero correlation for numeric variables.
  • Causal claims need a design that rules out the alternatives: randomised experiments (assigning X at random breaks every link with confounders), or explicit causal models and adjustment for confounders in observational data.

7The code

The whole analysis, without any statistics library (independence.py also contains the incomplete gamma function and a SciPy cross-check; the browser version is in js/stats.js):

from collections import Counter

def contingency(pairs):                      # pairs = [(x, f), ...]
    rows = sorted({x for x, _ in pairs}); cols = sorted({f for _, f in pairs})
    cnt = Counter(pairs)
    return rows, cols, [[cnt[(x, f)] for f in cols] for x in rows]

def independence_test(O):
    r, c = len(O), len(O[0])
    row = [sum(O[i]) for i in range(r)]                          # n_i.
    col = [sum(O[i][j] for i in range(r)) for j in range(c)]     # n_.j
    n = sum(row)
    E = [[row[i] * col[j] / n for j in range(c)] for i in range(r)]            # expected under independence
    chi2 = sum((O[i][j] - E[i][j]) ** 2 / E[i][j] for i in range(r) for j in range(c))
    df = (r - 1) * (c - 1)
    return chi2, df, E                                            # p = chi2_sf(chi2, df)
const rowTot = O.map(r => r.reduce((a, b) => a + b, 0));
const colTot = O[0].map((_, j) => O.reduce((a, r) => a + r[j], 0));
const n = rowTot.reduce((a, b) => a + b, 0);
const E = O.map((r, i) => r.map((_, j) => rowTot[i] * colTot[j] / n));
const chi2 = O.flat().reduce((s, o, k) => { const e = E.flat()[k]; return s + (o - e) ** 2 / e; }, 0);
const df = (O.length - 1) * (O[0].length - 1);
const p = chi2sf(chi2, df);          // upper tail of the chi-square distribution
