1The problem

The standard normal density is φ(t) = e−t²/2/√(2π) and its cumulative distribution function is

Φ(x) = P(Z ≤ x) = ∫−∞x φ(t) dt

Following Hogg–McKean–Craig (section 3.4), φ is a legitimate density because I = ∫0∞ (2/√π) e−x² dx satisfies I² = 1: writing I² as a double integral and passing to polar coordinates gives 1, and the substitution z = √2 x turns it into ∫−∞∞ φ = 1. The same notes observe that the integrand has no elementary antiderivative, so probabilities are read from a table or computed with a power series, as we do here. Two properties are used everywhere below:

Φ(−x) = 1 − Φ(x)  (symmetry of φ)     Φ(x) = 1/2 + ∫0x φ(t) dt  (for any real x)

2Why Φ is not an elementary function: Liouville’s theorem

Elementary functions are those built from constants and x with finitely many sums, products, quotients, compositions, roots, exponentials and logarithms. Differentiating an elementary function always gives an elementary function, but integrating does not: the question is which integrals stay elementary. Liouville (1830s) answered it for exponentials:

Theorem (Liouville; Ostrowski, Rosenlicht). Let f and g be rational functions, g non-constant. Then ∫ f(x) eg(x) dx is an elementary function if and only if there is a rational function h such that f = h′ + g′ h. In that case the antiderivative is h(x) eg(x).

Application. ∫ e−t²/2 dt has f = 1, g = −t²/2, g′ = −t. We would need a rational h with

h′(t) − t·h(t) = 1. Write h = P/Q in lowest terms and show that no such h exists: (a) If Q is not constant, let c be a root of Q of multiplicity m ≥ 1. Then h′ has a pole of order m+1 at c, while t·h has a pole of order at most m. So h′ − t h has a pole at c and cannot equal 1. (b) So h is a polynomial of degree d ≥ 0 (h = 0 gives 0 ≠ 1). Then t·h has degree d+1 with leading coefficient lc(h), and h′ has degree d−1: h′ − t h has degree d+1 ≥ 1, so it is not the constant 1. Contradiction: no rational h exists ⇒ ∫ e−t²/2 dt, and hence Φ, is not elementary.

There is no contradiction with the elementary value ∫−∞∞ φ = 1: a definite integral between special limits may be elementary (polar-coordinates trick) even if the antiderivative is not. What fails is a closed formula for Φ(x) at general x.

3The error function: an exact representation that still needs numerics

Since no elementary function does the job, one defines a new “special” function by the integral itself:

erf(z) = (2/√π) ∫0z e−s² ds,   erfc(z) = 1 − erf(z) Φ(x) = ½ [ 1 + erf(x/√2) ] = ½ erfc(−x/√2) Proof: in ∫0x φ(t) dt put t = √2 s; then ∫0x/√2 e−s² ds/√π = erf(x/√2)/2.

This is an exact analytic representation: Φ is expressed without approximation through erf, which has an everywhere-convergent Maclaurin series, erf(z) = (2/√π) ∑k≥0 (−1)k z2k+1 / (k!(2k+1)), and well-known properties (odd, erf(∞) = 1, erf′ = 2e−z²/√π).

But numerical methods are still needed, because naming a function is not computing it: the value erf(z) at a general z is a transcendental number which can only be reached through an infinite sum, an infinite fraction or an integral, and a computer has to stop after finitely many operations in finite-precision arithmetic. Every practical implementation (the C library, R, NumPy/SciPy, …) therefore uses a truncated series, a continued fraction or minimax rational approximations on several intervals. The choice matters for accuracy (cancellation in alternating series, relative accuracy in the tails where Φ ≈ 10−16) and for speed: this is what the rest of the page measures.

The recommended code

const phi = x => Math.exp(-0.5 * x * x) / Math.sqrt(2 * Math.PI);

function posSeries(x) {                 // Phi(x) = 1/2 + phi(x) * sum x^(2k+1) / (2k+1)!!
  let term = x, sum = x;
  for (let k = 1; k < 5000; k++) {
    term *= x * x / (2 * k + 1); sum += term;
    if (k > x * x / 2 && Math.abs(term) < 1e-17 * Math.abs(sum)) break;
  }
  return 0.5 + phi(x) * sum;
}
function upperTail(x) {                 // Q(x) = P(Z > x), x > 0, Lentz's continued fraction
  let f = x, C = x, D = 0;
  for (let k = 1; k < 3000; k++) {
    D = 1 / (x + k * D); C = x + k / C; const d = C * D; f *= d;
    if (Math.abs(d - 1) < 1e-16) break;
  }
  return phi(x) / f;
}
function normalCdf(x) {
  if (x >= 0) return x < 3 ? posSeries(x) : 1 - upperTail(x);
  return x > -1.5 ? posSeries(x) : upperTail(-x);
}

The same methods are in js/ncdf.js (browser) and normal_cdf.py (Python, compared with math.erfc).
