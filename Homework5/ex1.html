1Two ways of slicing

Both definitions approximate ∫ab f as a sum of “height × width” terms. They differ in which axis is cut. A classical image: to count a pile of coins, Riemann takes them in the order in which they lie on the table and adds their values one by one; Lebesgue first sorts them by value and then adds (value) × (how many coins have that value).

Riemann (domain partition). Cut [a, b] into n cells of width h = (b−a)/n and pick a tag ti in each cell:
Rn = ∑i f(ti) h
Tags used here: left end, midpoint. Darboux sums use the exact infimum / supremum on every cell: Ln = ∑ inf f · h ≤ ∫ f ≤ Un = ∑ sup f · h. f is Riemann integrable when Ln and Un have the same limit.
Lebesgue (range partition). Cut the range [m, M] into N bands yk = m + k·δ and look at the preimages Ek = f−1([yk, yk+1)):
SN = ∑k yk · μ(Ek),   μ(Ek) = G(yk+1) − G(yk)
where G(t) = μ{x : f(x) < t} is the distribution function of f. Lower sum: level yk; upper sum: yk+1; mid-level sum: yk + δ/2. The last band is closed, so the maximum is not lost. This is the sum of the simple function φ ≤ f that is constant on each Ek.

How the measure of the preimage is obtained. The Lebesgue approach needs μ(Ek), i.e. it must be able to “invert” f. For our functions G is available in closed form (for example G(t) = 2 arcsin t for sin on [0, π], G(t) = √t for x²) or by a root search (bisection for sin x / x). We call this the exact-preimage Lebesgue sum. Where G is not known one can estimate μ(Ek) from M sample points (a histogram of the values of f): the sampled-preimage sum, which costs M evaluations of f but needs no inverse.

Hypotheses: for a bounded f on [a, b], Riemann integrable ⇔ f is continuous almost everywhere (Lebesgue’s criterion). Lebesgue integrable ⇔ f is measurable (and ∫|f| < ∞). Every Riemann integrable function is Lebesgue integrable with the same value; the converse fails (Dirichlet) and the improper case 1/√x is covered by Lebesgue but not by the proper Riemann integral.

6Where the two approaches behave differently

Dirichlet and Thomae

The Riemann sums of these functions depend on the tags, because every cell contains rational and irrational numbers. With rational tags k/n the Dirichlet sum is always 1; with irrational tags (k/n + √2/(10n)) it is always 0. The Darboux sums are stuck at 0 and 1, so there is no common limit: Dirichlet is not Riemann integrable. For the Lebesgue sum nothing is ambiguous: the rationals have measure 0, the irrationals measure 1, hence ∫ f = 1·0 + 0·1 = 0.

Thomae’s function is different: it is continuous at every irrational and discontinuous only on the rationals (measure 0), so it is Riemann integrable, and its upper Darboux sum shrinks to 0 (only finitely many points have f ≥ ε). Both integrals are 0.

Floating-point numbers are all rational, so a program can never “evaluate” the Dirichlet function on a random double; here the tags are handled symbolically (exact fractions p/q, or “an irrational”). This is itself a hint of why the Lebesgue viewpoint, which only needs the measure of the sets, is the right one for such functions.

Improper case: 1/√x on (0, 1]

The left-tag sum needs f(0) = ∞ and the upper Darboux sum is infinite: the proper Riemann integral does not exist. Midpoint and lower sums converge, but slowly, with order only 1/2, because the singular cell carries an error of order √h. The Lebesgue sum needs no special treatment of the point 0: the unbounded range is cut at a level Y (we take Y = 1 + √N), and the discarded tail contributes about 1/Y.
